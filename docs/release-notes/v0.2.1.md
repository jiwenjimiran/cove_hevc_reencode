# HEVC/AV1 Reencode 0.2.1

HEVC now uses quality-targeted variable bitrate on NVIDIA and AMD. Aggressive
retries default to off, avoiding automatic quality reductions to force savings.

- NVIDIA HEVC switches from constant QP to VBR/CQ; both NVIDIA codecs use p7,
  32-frame lookahead, and spatial AQ strength 8 by default.
- AMD HEVC switches to QVBR with its quality preset; AMD AV1 retains QVBR.
  Both enable preanalysis explicitly. AMD quality parity is not hardware-tested.
- Calibrated NVIDIA defaults: HEVC normal/low-bitrate CQ 28/30; AV1 34/36.
  Codec numbers differ intentionally. See the repository quality comparison for
  VMAF, file sizes, worst-second results, and limitations.
- Health checks exercise the production argument builder.
- Reusable local packaging, CI ZIP artifacts, and tag-triggered releases.

## Existing installations

Saved settings are preserved. To adopt the defaults, disable **Enable Aggressive
Retries**, set HEVC CQ to 28 and low-bitrate CQ to 30, and set AV1 CQ to 34 and
low-bitrate CQ to 36. The NVENC preset remains p7. Existing enabled retries retain
their previous behavior, including progressively lower quality and a relaxed
savings threshold.

This is lossy reencoding. The samples do not establish equal quality on every
file, and difficult material may not shrink. No originals are changed by the
benchmark or packaging scripts. Install the attached ZIP through Cove.
